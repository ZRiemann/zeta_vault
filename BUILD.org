#+TITLE: zeta_vault build entry

* Unified build entry
The root entry uses =./zbuild.py <command> [deliverable ...] --profile release|debug=.
The profile defaults to =release=. Run =./zbuild.py list= for targets and capabilities,
and append =--dry-run= to inspect scope without executing. Unsupported actions fail.
=check= performs non-mutating source/compiler checks; =test= prepares and runs native
correctness suites. =run= requires an existing output; =dev= builds and runs (or
uses the application's native watcher). Arguments after =--= are forwarded without
logging. Cleanup affects the owning native engineering unit and selected profile;
the plan names affected sibling outputs. Installations, data and shared caches stay intact.
Host preparation and deployment are separate operations.

Default: =zeta_vault_c zeta_vault_cpp zeta_vault_server zeta_vault_ctl=.
The C example is explicit and there is no default runtime application.
The C ABI and C++ wrapper have separate install components; installing the wrapper
or ctl includes the required C ABI library. Server installation is independent. =dev= builds and runs once. Password input, socket, credentials
and data ownership are unchanged; never pass passwords in command arguments.
#+begin_src sh
./zbuild.py build
./zbuild.py test --profile debug
./zbuild.py install zeta_vault_c
./zbuild.py run zeta_vault_ctl -- --help
#+end_src

* Explicit run registration
The server, ctl and C example are explicitly registered; C/C++ libraries are
not runnable. Native =add_run_target()= supplies executable/default arguments/cwd
through generated =.zeta-run= metadata, with no source-scanning fallback.
After updating Forge, refresh an existing configured tree without compiling:
=cmake -S . -B build/Release= (or =build/Debug=). Cached options are preserved;
an example disabled in that tree requires selecting it with =build= or =dev=.
This changes launcher metadata only, not password input, sockets, credentials,
Vault data, installations or running services. =run= never builds implicitly.
