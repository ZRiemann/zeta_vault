#+TITLE: zeta_vault Release History

* v1.2.0

- Add ~zeta_vault_ctl show-utf8~ for explicit terminal-only display of stored
  single-line UTF-8 secrets.
- Reject non-terminal stdout, empty or non-UTF-8 values, multi-line values, and
  terminal-control characters before revealing a secret through ~show-utf8~.
- Keep the C ABI, protocol v1, and storage v1 formats unchanged.

* v1.1.1

- Preserve client-creation diagnostics per thread so C callers can inspect
  connection failures without a client handle.
- Include detailed creation diagnostics such as ~connect: No such file or
  directory~ in C++ wrapper and CLI errors.
- Raise the backward-compatible C API version to 0.2.1 while keeping protocol
  v1 and storage v1 unchanged.

* v1.1.0

- Read and validate ~put-utf8~ input before opening the server connection, so
  interactive typing time is not constrained by socket timeouts.
- Add regression coverage that proves hidden input completes before a failed
  connection attempt.
- Keep the C ABI, protocol v1, and storage v1 formats unchanged.

* v1.0.0

- Add ~zeta_vault_ctl put-utf8~ for hidden single-line UTF-8 secret entry
  without plaintext files, process arguments, or environment variables.
- Reject empty, oversized, NUL-containing, and malformed UTF-8 input while
  preserving valid single-line bytes without trimming or normalization.
- Reuse one wipeable ~/dev/tty~ input implementation for the server master
  password and CLI UTF-8 secrets.
- Keep the C ABI, protocol v1, and storage v1 formats unchanged.

* v0.3.0

- Add and install ~zeta_vault_ctl~ with ~put~, ~get~, ~remove~, and sorted
  ~list~ operations.
- Add protocol-v1 list request/response messages and list operations to the C
  ABI and header-only C++ wrapper; raise the C ABI version to 0.2.0.
- Restrict secret identifiers to lowercase C-style identifiers matching
  ~^[a-z][a-z0-9_]{0,62}$~ throughout clients, protocol, and storage.
- Reject legacy vault files containing identifiers outside the v0.3.0 rule
  without disclosing those identifiers in diagnostics.
- Enforce private input files and atomic, no-overwrite mode-0600 output files
  for CLI plaintext secret transfer.

* v0.2.0

- Add the Linux Unix-domain-socket server with bidirectional peer UID checks.
- Add a versioned request-response protocol encoded with zpp/wire.
- Add Argon2id and XChaCha20-Poly1305 encrypted single-file storage.
- Add atomic persistence, mode-0600 files, secure memory, and process locking.
- Add the stable C ABI client library and header-only C++ RAII wrapper.
- Add the shared zeta_forge build launcher, tests, a C example, install
  exports, and bilingual documentation.

* v0.1.0

- Bootstrap the empty repository on the online initialization branch.
